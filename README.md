# BookStore Database

## Description

This project contains a MySQL database for managing a bookstore.

## Database Tables

- Books
- Customers
- Orders
- Order_Items
- Admins

## Technologies Used

- MySQL
- MySQL Workbench
- SQL

## Features

- Store book information
- Manage customer information
- Manage customer orders
- Store order items
- Manage admin users

## How to Run

1. Open MySQL Workbench.
2. Open `bookstore.sql`.
3. Select the required database.
4. Execute the SQL script.
5. Run the queries to view and analyze the data.
